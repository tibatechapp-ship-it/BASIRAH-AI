# BASIRAH-AI

برنامج **بصيرة** منصة ذكية لفهرسة وتصنيف وتنظيم المكتبات الرقمية والبحوث العلمية تلقائياً. يعتمد على تحليل المحتوى، واكتشاف العلاقات بين الملفات، وإزالة التكرار، وبناء قاعدة معرفية قابلة للبحث والاستكشاف.

**BASIRAH AI** هو منصة معرفية ذكية تهدف إلى تحويل المكتبات الرقمية والبحوث العلمية من ملفات مبعثرة إلى قاعدة معرفية منظمة وقابلة للبحث والتحليل.

## الرؤية

الانتقال من إدارة الملفات إلى إدارة المعرفة.

## المميزات

- تصنيف المحتوى حسب الموضوع (القرآن، العقيدة، الفقه، السيرة).
- دعم ملفات PDF و TXT و DOCX.
- مسح تلقائي متكرر داخل مجلد المكتبة.
- تطبيع النص العربي (إزالة التشكيل، توحيد الألفات والتاء المربوطة).
- اكتشاف الملفات المكررة بواسطة تجزئة المحتوى (SHA-256).
- إنشاء المجلدات تلقائياً.
- معالجة آمنة لأسماء الملفات المتكررة.
- **API احترافي باستخدام FastAPI مع قاعدة بيانات PostgreSQL و pgvector.**
- **بحث دلالي (Semantic Search) باستخدام نماذج تضمين عربية متعددة اللغات.**

## متطلبات التشغيل

- Python 3.10+
- pytest (للاختبارات)
- flake8 (للفحص الساكن)
- PyMuPDF (لقراءة PDF)
- python-docx (لقراءة DOCX)
- PostgreSQL مع امتداد pgvector (للـ API)

## التثبيت

باستخدام conda:

```bash
conda env create -f environment.yml
conda activate basirah-ai
pip install -r requirements.txt
```

أو باستخدام pip:

```bash
pip install -r requirements.txt
```

## التشغيل باستخدام Docker

```bash
docker compose up --build
```

سيتم تشغيل:
- قاعدة بيانات PostgreSQL مع pgvector على المنفذ `5432`
- الـ API باستخدام FastAPI على المنفذ `8000`

## واجهة برمجة التطبيقات (API)

بعد التشغيل، يمكنك زيارة وثائق التفاعلية:

```
http://localhost:8000/docs
```

### نقاط النهاية الرئيسية

- `GET /health` — التحقق من حالة النظام.
- `POST /documents/upload` — رفع مستند وفهرسته والبحث الدلالي.
- `GET /documents/` — قائمة المستندات المفهرسة.
- `GET /documents/search?q=...` — البحث الدلالي باللغة العربية.
- `POST /library/organize` — رفع أرشيف ZIP وتنظيم محتواه تلقائياً.

## الاستخدام

### الواجهة السطرية (CLI)

```bash
python src/organizer.py
# أدخل مسار المكتبة عند الطلب
```

سيقوم البرنامج بمسح الملفات المدعومة، وتصنيفها، ونقلها إلى مجلدات حسب الفئة.

### الواجهة الرسومية (GUI)

```bash
python src/organizer.py --gui
```

أو مباشرةً:

```bash
streamlit run src/gui.py
```

تفتح واجهة ويب احترافية تدعم اللغة العربية واتجاه RTL، وتتيح:

- رفع مكتبة مضغوطة بصيغة ZIP.
- تنظيم الملفات تلقائياً وتنزيل النتيجة.
- اكتشاف الملفات المكررة داخل المكتبة.
- عرض هيكل المكتبة المصنفة.
